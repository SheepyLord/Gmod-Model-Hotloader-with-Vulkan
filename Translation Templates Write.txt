Vulkan Kernel Model Hot Loader with Softbody Simulation (Utility / Tool)

[b]Common model formats could be now be hot loaded into Garry's Mod in game as static / character models. It enables [url=https://en.wikipedia.org/wiki/Soft-body_dynamics]softbody simulation[/url] if the model supports and also replaces the rendering API of Garry's Mod to [url=https://en.wikipedia.org/wiki/DXVK]Vulkan-DXVK[/url] which by itself allows the game to have higher performance. [/b]

[h1]Warning! ⚠ [/h1]
[b]An open-source binary module is required[/b] for your game client/server to allow gmod to load models in your local computer and implement Vulkan rendering API. The source code and build process is fully public in GitHub action with verifiable SHA256 hash. Please visit the repo for more details.
Download the binary module here: [url=https://github.com/SheepyLord/Gmod-Model-Hotloader-with-Vulkan/releases] GitHub: SheepyLord/Gmod-Model-Hotloader-with-Vulkan[/url]

[h1]Introduction[/h1]
Have you noticed that, unlike most modern Sandbox games, you have to port a model or character into Source Engine format before you can actually use it in Garry's Mod? Well, that is no longer the case. Here we introduce "Vulkan Kernel Model Hot Loader with Softbody Simulation (VKMHL-SS)" to fully address this issue.

This addon writes the model data directly into the runtime game memory and the rendering pipeline in Vulkan / OpenGl, thereby hotloads models into Gmod. The imported model is algorithmically identical to a complied Source engine model, at least at the engine level. This will make the non-multiplayer model porting process obsolete with some performance tradeoff when too many models are in player's view. To optimize this, we ended up re-wiring the rending API of Gmod to Vulkan, this means that native Ray-tracing, DLSS / FSR is now possible and will be implemented as a follow up project.

For static objects, this addon supports: .pmx, .fbx, .obj, .glb and .blend
For dynamic characters, this addon supports: MMD formatted .pmx (Polygon Model eXtended for MikuMikuDance) and Standardized .VRM (Virtual Reality Model).

[h1]Возможности[/h1]
- Перевод API рендеринга Gmod с OpenGL на Vulkan: производительность в очень сложных сценах должна заметно вырасти, а нагрузка на GPU — снизиться на 50%.
- Импорт практически любой модели персонажа в Garry's Mod в качестве модели игрока/НИПа и рэгдолла
- Модели хранятся на сервере и доступны всем клиентам (бинарный модуль должен быть установлен и на клиенте, и на сервере)
- Экспорт импортированных моделей в виде аддонов Garry's Mod и публикация в Мастерской (этот аддон обязательно нужно указать как зависимость, иначе они будут бесполезны)
- Сохранение / загрузка между сессиями

[h2]Как использовать[/h2]
[list=1]
[*]Подпишитесь на этот предмет в Мастерской.
[*]Скачайте бинарный модуль для Gmod с открытым исходным кодом с [url=https://github.com/SheepyLord/Gmod-Model-Hotloader-with-Vulkan/releases] GitHub: SheepyLord/Gmod-Model-Hotloader-with-Vulkan[/url].
[*]Перетащите папку в steamapp/GarrysMod и объедините её с существующей.
[*]Запустите Garry's Mod.
[*]Нажмите Q и перейдите на вкладку [b]Внешние модели[/b] (External Models).
[*]Выберите модели на своём компьютере с помощью кнопки импорта.
[*]Подождите несколько секунд, пока модель импортируется (зависит от сложности).
[*]С помощью кнопок размещайте, создавайте и используйте импортированные модели.
[/list]

[h3]Примечания[/h3]
- При импорте этот аддон снимает все ограничения движка Source и поддерживает модели, содержащие до 1 миллиона вершин, 32 767 костей, ключей формы, материалов, групп вершин и твёрдых тел. Теперь ограничение — только ваш компьютер.
- Аддон использует физический движок Bullet с ускоренной на GPU через Vulkan симуляцией твёрдых и мягких тел и множеством оптимизаций, что позволяет детально симулировать одежду и волосы на моделях персонажей.
- Симуляция физики одежды, волос и тела выполняется только на клиенте; стандартная физика Havok в Gmod не изменяется.
- Импортированные модели поддерживают моддинг и совместимы с большинством стандартных точек входа и методов Lua.
- Экспортированными моделями смогут пользоваться только игроки, у которых установлен этот аддон.
- Оптимизировано для RTX-Remix; если вы используете Remix, скачайте пакет OpenGL-Remix.
